# 电子礼簿系统   2026-8-26

一款开源、免费、完全本地运行的单页 Web 应用，旨在为各类红白喜事（如婚庆、寿宴、白事等）提供一个现代化、安全、高效的礼金（份子钱）管理解决方案。它彻底告别了传统的手写礼簿，通过数字化的方式解决了记录、统计、查询和存档的全部流程，以**简单易用**为最高设计原则。

## 核心特性

### 数据主权，绝对安全

* **拔线能用**：纯 HTML 单页应用，无服务器交互，数据 100% 本地存储，不依赖任何云服务器。
* **金融级加密**：全量数据采用 **AES-256** 加密落库（IndexedDB），管理密码 **SHA-256** 哈希保护。即便电脑丢失，文件被拷走也无法破解。

### 极致的录入体验

* **秒级记账**：姓名、金额、收款方式（现金 / 微信 / 支付宝）、备注，全键盘操作，回车即录。
* **智能风控**：实时检测重名、重复金额，防止“记重了、记错了”。
* **自动大写**：输入数字，自动生成规范中文大写（如：壹仟元整）。
* **语音播报**：支持 TTS 语音朗读（“张三 贺礼 一千元整”），可自定义音色与起报金额，方便宾客现场核对金额，又能撑场面。
* **随时可改**：录错了支持纠错与作废，修改姓名/金额需管理员密码确认，全程留痕可回溯。

### 双屏互动 & 仪式感

* **访客副屏**：支持开启副屏页面，实时投射数据到外接屏幕/电视，主屏录入，副屏展示。
* **隐私脱敏**：副屏可开启隐私模式，仅展示最新记录全名，历史记录自动打码。
* **收款码展示**：副屏支持自定义上传展示东家收款码，方便宾客现场扫码。
* **双色主题**：内置「喜庆红」与「肃穆灰」两套皮肤，适应红白喜事不同场景。

### 专业级报表与归档

* **真·PDF 引擎**：双引擎可选——「浏览器另存为 PDF」（文件小，PC 端）与「PDF-Lib 引擎」（文件稍大，兼容 PC/移动端），支持**自定义字体、封面图、背景纹理**，生成精美的电子礼簿。
* **智能分批**：数据量超大时自动分卷生成，防止浏览器内存溢出。
* **审计留痕**：全链路记录修改历史（时间轴），支持**软删除（作废）**，每一笔变动都有迹可循。
* **双重备份**：
  * **Excel**：标准 `.xlsx` 报表，含完整修改日志。
  * **数据文件**：导出加密的 BIN 备份，支持跨设备全量恢复。

### 极简信息模型

礼簿只保留最核心的字段：**姓名、金额、收款方式、备注**。没有多余的等级、礼品、联系方式等字段，创建礼簿也无需填写起止时间——打开就能记，记录按录入先后顺序排列。打印封面与文件名上的日期自动取礼簿创建日期。

### 快速上手指南
* **下载文件**：获取 **index.html**、**guest-screen.html** 及 **static** 文件夹，并将它们放在同一个目录下。
* **打开应用**：使用现代浏览器（如 Chrome, Firefox, Edge）打开 **index.html** 文件。
* **创建新礼簿**：
  * 填写礼簿名称、设定一个您能牢记的**管理密码**。
  * 选择礼簿主题颜色（喜庆红 / 肃穆灰），可填写记账人姓名。
  * 点击“创建并进入”按钮。
* **开始录入**：在主界面左侧的表单中，依次填写来宾姓名、金额、收款方式和备注，然后点击“确认录入”。
* **管理与导出**：使用右侧的功能按钮进行查找、打印、导出 Excel 或查看详细统计。
* **切换或返回**：点击主界面左上角的标题，可以方便地切换到其他礼簿或返回创建页面。
* **修改设置**：主界面菜单中可随时修改礼簿名称、记账人、语音音色、主题颜色、副屏脱敏与 PDF 引擎；「礼簿样式设置」可自定义封面、字体与背景。

你只需要一个代码编辑器（推荐 **VS Code**）和一个现代浏览器（Chrome/Edge）。

### 启动开发

虽然直接双击 `index.html` 可以运行，但为了避免浏览器的安全策略限制（如本地文件访问限制、模块加载跨域等），**强烈建议使用本地静态服务器**运行。

* **方式一（推荐）：VS Code Live Server**

  1. 安装 VS Code 插件：[Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer)。
  2. 右键选择 **"Open with Live Server"**。

***方式二：Python (Mac/Linux/Win)**
  在项目根目录下打开终端，运行：

  ```bash
  # Python 3
  python -m http.server
  # 访问 http://localhost:8000
  ```

### 项目结构

```
├── index.html                  # 主入口（核心代码均内嵌于此，方便单文件分发）
├── guest-screen.html           # 副屏显示页面
└── static/                     # 静态资源目录
    ├── tailwindcss.js          # 样式引擎
    ├── xlsx.full.min.js        # Excel 导出库
    ├── pdf-lib.min.js          # PDF 生成引擎
    ├── fontkit.umd.min.js      # PDF 字体解析
    ├── GiftListPDFGenerator.js # 礼簿 PDF 渲染类（GiftRegistryPDF）
    ├── crypto-js.min.js        # 加密库
    ├── gridjs.umd.js           # 表格组件
    ├── remixicon.*             # 图标
    ├── pell.min.js / .css      # 副屏富文本编辑器
    ├── *.ttf                   # 中文字体（用于 PDF 生成）
    └── *.jpg / *.webp          # 封面、背景、收款码等图片素材
```

### 部署上线

本项目是纯静态资源，部署非常简单：

* **直接上传**：将所有文件上传至 GitHub Pages、Vercel、Nginx 或任何静态文件服务器。
* **无需编译**：不需要执行 `build` 命令，源码即产物。

## 技术

* **Core**: Vanilla JS (ES6+), OOP 架构
* **Style**: Tailwind CSS
* **Database**: IndexedDB（数据加密存储）
* **Crypto**: CryptoJS (AES-256)
* **Export**:
  * `SheetJS` (Excel)
  * `PDF-Lib` & `Fontkit` (客户端 PDF 生成)
* **UI Components**: Grid.js (表格), RemixIcon (图标), Pell (富文本)
